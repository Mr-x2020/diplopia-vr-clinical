# 🧠 Diplopia VR — Open-Source Dichoptic Amblyopia Therapy Engine

نظام تدريب بصري ثنائي الرؤية (Dichoptic VR) مفتوح المصدر للبالغين والأطفال، مبني على بروتوكول **James Blaha** والمبادئ السريرية لمنصة **Vivid Vision** وأبحاث **McGill University (Robert Hess et al.)**.

---

## 🎯 البروتوكول العلاجي الثلاثي (The Clinical Triad)

| التمرين | الآلية البصرية | الهدف السريري والمسار العصبي |
| :--- | :--- | :--- |
| **Tetris** | 2D Contrast Balancing | كسر القمع القشري البصري (*V1 Suppression*) عبر موازنة التباين التكيفي. |
| **3D Breakout** | Stereopsis & Smooth Pursuit | تحفيز إدراك العمق على المحور $Z$ وتتبع الأجسام السريعة (*Area MT / V5*). |
| **Gaze Fixation** | Anti-Saccade & Fixation Stability | استقرار التثبيت المركزي وتقليل الرأرأة الدقيقة (*Micro-saccadic Instability*). |

---

## 🛡️ ركائز السلامة السريرية (Safety Protocols)

1. **إخلاء مسؤولية طبي مسبق:** فحص موانع الاستخدام (الصرع الحركي، الشفع المستمر، الجراحات العينية الحديثة).
2. **معايرة المسافة بين الحدقتين (IPD):** ضبط النطاق التشريحي (54mm–74mm) لمنع تشنج التقارب العيني الصداعي.
3. **المنشور الرقمي (Digital Prism Offset):** معايرة زوايا الحول ($X, Y$) لضمان سقوط الصورة على بؤرة الشبكية (*Fovea*).
4. **زر الطوارئ الفوري (Panic Button):** زر `Escape` على لوحة المفاتيح أو `Select / Back` على يد التحكم لإطفاء المشهد فوراً عند حدوث إجهاد.
5. **توازن التباين التكيفي:** رفع تباين العين السليمة بنسبة 2% فقط عند كل سلسلة نجاح متواصلة، وتصفير السلسلة عند الخطأ.

---

## 🚀 التشغيل المباشر عبر المتصفح

لا يتطلب النظام تثبيت تطبيقات متجرية، ويعمل مباشرة عبر متصفحات الهواتف الحديثة (Chrome / Safari):

1. ادخل إلى رابط المنصة المشفر بـ HTTPS.
2. اقرأ التحذير الطبي وأكّد الموافقة.
3. حدد العين الكسولة (اليسرى أو اليمنى) واختر التمرين.
4. اضبط مسافة بؤبؤي العينين (IPD).
5. ضع الهاتف داخل نظارة VR (Cardboard / VR Box).
6. حرّك عصا التحكم حتى يتطابق الصليب داخل الدائرة (معايرة المنشور الرقمي).
7. اضغط `A` أو `Enter` لبدء الجلسة.

## 📊 تصدير السجل الطبي (Clinical Analytics)

يقوم المحرك بحفظ مقاييس الجلسات تلقائياً في التخزين المحلي (`localStorage`):
* مدة التحفيز الفعالة بالثواني (مع تجميد العداد تلقائياً عند إخفاء التبويبة).
* منحنى تصاعد التباين ($15\% \to 85\%$).
* زمن الاستجابة العصبي بالمللي ثانية ($RT$) لتمرين التثبيت.
* تصدير تقرير شامل بصيغة `Amblyopia_VR_Report_YYYY-MM-DD.json` لتقديمه لأخصائي الحول.

## 🛠️ المتطلبات التقنية (Hardware & Software)

* **الهاتف:** شاشة بدقة 1080p أو أعلى ومعدل تحديث 60Hz+.
* **النظارة:** نظارة واقع افتراضي للهواتف تدعم تعديل العدسات (مثل VR Box أو Google Cardboard).
* **التحكم:** ذراع تحكم صغيرة بتقنية البلوتوث (Bluetooth Gamepad) في وضع Game Mode.
* **المتصفح:** يدعم WebGL 1.0/2.0 مع اتصال HTTPS إلزامي.
